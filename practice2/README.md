# Эмулятор оболочки (ПР №1, вариант 5)

## 1. Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС на Python (tkinter).
Реализован этап 1: окно с именем VFS в заголовке, парсер
"команда + аргументы по пробелам", команды-заглушки `ls`, `cd`
и команда `exit`.

## 2. Функции и настройки
- Заголовок окна содержит имя VFS (пока `default`).
- Ввод разбивается по пробелам на команду и аргументы.
- `ls`, `cd` - заглушки: выводят своё имя и аргументы.
- `exit` закрывает окно.
- Неизвестная команда выводит `имя: команда не найдена`.

## 3. Сборка и тесты
Нужен Python 3.8+ с tkinter (на macOS - установщик с python.org).

```
make test
```
Без make: `PYTHONPATH=src python3 -m unittest discover -s tests -v`

## 4. Примеры
```
python3 src/main.py
```
Ввод в окне:
```
$ ls -l /tmp
команда: ls, аргументы: ['-l', '/tmp']
$ cd home
команда: cd, аргументы: ['home']
$ abc
abc: команда не найдена
$ exit
```
