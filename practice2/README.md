# Эмулятор оболочки (ПР №1, вариант 5)

## 1. Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС на Python (tkinter).
Работает с виртуальной файловой системой (VFS), которая целиком
хранится в памяти и загружается из CSV-файла.

Реализовано (этапы 1-3): окно с именем VFS в заголовке, парсер
"команда + аргументы по пробелам", команды-заглушки `ls`, `cd`,
команда `exit`, параметры запуска, стартовые скрипты с комментариями,
загрузка VFS из CSV (base64 для содержимого), вывод `motd` при старте.

## 2. Функции и настройки
Параметры командной строки:

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | CSV-файл с VFS. Без него создаётся пустая VFS `default` |
| `--script ПУТЬ` | Стартовый скрипт с командами эмулятора |

При запуске все параметры выводятся в консоль и в окно.

**Стартовый скрипт** - текстовый файл, одна команда на строку.
Комментарий начинается с `#` (до конца строки), пустые строки
пропускаются. В окне показываются и ввод, и вывод. Если встретился
`exit`, окно закрывается.

**Формат VFS (CSV)**, колонки `path,type,content`:

```
path,type,content
/motd,file,SGVsbG8=
/docs,dir,
/docs/deep/a.txt,file,dGV4dA==
```

- `type` - `dir` или `file`; `content` - base64 (пусто для папок);
- вложенность задаётся полным путём, недостающие папки создаются;
- `motd` в корне VFS выводится при старте.

Ошибки загрузки (нет файла, неверный заголовок/тип/base64) выводятся
в stderr, код возврата 1.

Команды: `ls`, `cd` (заглушки: выводят имя и аргументы), `exit`.

## 3. Сборка и тесты
Нужен Python 3.8+ с tkinter (на macOS - установщик с python.org).

```
make test        # unit-тесты
make demo        # все демо-скрипты
```
Без make: `PYTHONPATH=src python3 -m unittest discover -s tests -v`

## 4. Примеры
```
python3 src/main.py
python3 src/main.py --vfs examples/vfs/multi.csv
python3 src/main.py --vfs examples/vfs/deep.csv \
    --script scripts/startup_stage3.emu
bash scripts/demo_errors.sh      # обработка ошибок VFS
```
Готовые VFS: `examples/vfs/minimal.csv`, `multi.csv` (несколько файлов,
двоичный `data.bin`), `deep.csv` (4 уровня вложенности).
